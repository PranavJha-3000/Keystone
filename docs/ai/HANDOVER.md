- [ ] **Sign-off needed (D-010): election-id convention is INTEGER, and it conflicts with the existing circuits tests.** `BallotBox` derives the scope from the numeric value of `bytes32` (`electionScope(BigInt(id))`), because a `bytes32` cannot be turned back into a UTF-8 label.
